# Apple Silicon 本地视频理解

本地模式使用 Whisper Large V3 Turbo 转写语音，Qwen3-VL 4B 的 4-bit 版本分析抽样画面，同时承担总结、评分、陪伴和安全检查。模型推理不产生云端 API 调用费，仍消耗本机算力、电量和磁盘；模型下载、B 站采集与发布需要联网。无需另开模型服务器。

## 安装和网页配置

在 Apple Silicon Mac 上原生运行，推荐 Python 3.11；Docker Desktop 的 Linux 容器不能使用本机 Metal。已有 Docker 部署需在停止旧机器人后迁移数据，避免两个实例同时处理同一账号。

```sh
uv sync --locked --extra local --python 3.11
uv run --extra local bili-comment-bot prepare-local-models
uv run --extra local bili-comment-bot run
```

下载命令仅准备两个公开模型，首次需要数 GB 磁盘空间及网络。模型保存在 Hugging Face 默认缓存，后续推理仅从本地读取；缺依赖、缺模型或超时会失败，不自动下载，也不回退付费服务。每次 `uv run` 均保留 `--extra local`，防止 uv 移除可选依赖。

打开控制台的「本地模型」，点击「应用本地方案」后保存。它会把聊天和转写都切换为 `local_mlx`、开启无字幕转写和画面理解；不会更改发布许可。API 地址、API 模型名称和密钥在本地模式下不使用。仍需扫码登录 B 站，再启动机器人。

若改用 8B 模型，先在网页保存选择，停止机器人后再次执行模型下载命令，再启动。自定义 `--config` 时下载和运行使用同一参数。建议从 4B 开始，先模拟演练和检查生成质量。

## 约 20GB 可分配统一内存的默认值

| 项目 | 默认值与作用 |
|---|---|
| MLX 分配预算 | 16GB，为解码、Python 和其他程序留余量；不是整个进程的硬上限 |
| 模型调度 | 语音、视觉、文本共用串行队列；每个任务在独立子进程中执行，完成退出释放模型 |
| 图片 | 每批 4 帧，最长边 768 像素 |
| 整部视频帧数 | 最多 24 帧，均分到所有分 P，在各 P 内均匀采样 |
| 上下文 | 输入文字、图片 Token 和输出总计 8192 Token；超限失败而非截断 |
| 超时 | 每个本地任务最多 900 秒，超时或取消会终止并回收子进程 |
| 下载 | 字幕、音频、画面视频共用整部 64MB 默认预算；选择最低带宽的 AVC 画面轨道 |

不常驻模型会增加加载时间，优先保证内存能够释放。长视频或细节很多的画面可能超出下载/上下文预算，可在网页按实际机器情况调整。24 帧无法保证捕获快速剪辑或所有事件；不要把抽样结果理解为逐帧分析。此版本不分析音乐、音效或说话人身份。

## 证据与隐私

- 优先字幕；明确无字幕才转写语音。画面开关启用后独立分析各 P，也可处理无语音视频。
- PyAV 直接解码 MP4/AAC，无需单独安装 ffmpeg 命令；音频重采样为单声道 16kHz，转写保留分段时间戳并校验实际时长。
- 画面来源绑定 aid/CID、模型和实际抽帧时间。总结标注“抽样画面”，缺少语音证据时也会说明；认证、结构、网络或模型错误不会冒充无字幕/无语音。
- 文本和视觉描述进入相同来源审查、引用校验与输出审查。4B 模型并不保证安全判断和 JSON 输出总是正确；未知或契约失败继续阻止发布。
- 本地子进程不继承平台 Cookie、API 密钥或代理环境，媒体和请求放入私密临时目录并在完成/取消后删除。缓存只保存证据文字、时间与来源，不保存截图或媒体 URL；操作系统强制关机可能遗留临时文件。
- 配置网站只展示设置和脱敏状态，不展示私信、媒体、转写内容或模型原始日志。本地模式无需密钥。

缓存版本 `multimodal-v3` 包含本地模型、画面策略、语音后端和预算；配置变化后重新获取。画面与口述证据共享字数上限，缓存读取重新校验所有分 P 来源。

## 验证范围

离线回归覆盖本地模式不调用云端、串行排队、取消回收、分 P 覆盖、帧数预算、时间戳、损坏缓存、来源注入及网页配置。真实编解码测试使用自行生成的纯色视频和静音，不访问用户媒体。本次模型权重下载因网络速度过慢未完成，因此未宣称真实 MLX 端到端推理通过。真实 B 站媒体兼容和中文转写/视觉语义质量仍需按实际内容验收，不能由合成测试推断。

实现依据：[MLX-VLM](https://github.com/Blaizzy/mlx-vlm)、[MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper)、[PyAV](https://pyav.org/docs/stable/)。
