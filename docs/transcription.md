# 可选音频转写

本地 Whisper 适配及可选画面分析见 [本地模型](local-models.md)。以下为 API 转写模式；本地模式无需服务密钥。

默认 `evidence.transcription_enabled=false`。启用时，在网页「音频转写」填写独立的服务地址与密钥，在「字幕与证据」设置转写模型并开启转写。旧部署首次导入仍支持 `BILI_BOT_TRANSCRIPTION_API_KEY` 与 `BILI_BOT_TRANSCRIPTION_MODEL`；网页保存后以网页配置为准。不共用聊天模型密钥，不传 B 站 Cookie。服务须支持 OpenAI 风格 multipart `/audio/transcriptions`、`verbose_json` 与 segment 时间戳；缺配置或不支持时明确失败，不自动降级成无时间信息的文本。

优先全部分 P 字幕，只有轨道查询成功且列表为空，才尝试音频。轨道存在但语言不在配置列表，或字幕结构/认证/权限/网络错误，不转换成“无字幕”。音轨只选择受支持的 AAC、最低带宽及经过核对的 HTTPS CDN，音频流程不获取画面，不绕过访问限制；独立画面开关见本地模型说明。

直接上传 M4A，不启动解码器、shell 或临时媒体文件。上传前校验 MP4 顶层容器盒边界和必要结构；这不是声学解码或语音质量证明。服务解码返回 duration，与分 P 时长偏差超过 2 秒便失败；另校验有限有序时间、非空文本及文本/时间段一致性。DASH 容器与供应商兼容仍需真实验收。

整部视频共用时长、下载字节、文本和转写次数预算。单次默认最多 24,000,000 字节，超过预算停止，不截断上传、自动分块或隐式转换。单视频默认最多 20 次，单进程每分钟最多 20 次；分钟预算是内存状态，重启清空。并发默认 1，总超时默认 120 秒，响应字节有限。只选择一个验证后的地址，传输失败不自动尝试其他地址。

所有 P 成功且未截断，才批准整部口述证据。每 P 保存 CID/page、来源类型、语言、模型、时间和限制，不保存媒体 URL、原始音频或密钥。缓存 `multimodal-v3` 的指纹包含转写服务/模型/语言/非秘密后端标识和各项预算；替换服务也应更新 `backend_id`。指标与评论独立刷新。尾注按真实来源说明字幕、音频转写或混合，未开启视觉时明确未分析画面，开启时明确仅有抽样画面；转写文字经过相同来源安全检查。

客户端无 HTTP 自动重试。超时可能已经计费，不能当作未请求。业务任务在持久退避后可再次获取失败证据，属于新的有预算请求，可能再次计费；结合指标和供应商限额观察。失败不缓存成成功空文本。明确无音频或超预算返回证据不足并生成人格说明；临时失败保留事件和退避，不批准内容动作或重发平台写入。

离线音频盒、字幕和服务响应是自写合成数据，不是可播放媒体或实际模型答案。测试验证契约、范围、来源、限额、取消清理、退避和零平台消息写入。真实音频兼容、误识别、语言质量与成本尚未验收。

依据：[文件转写格式与大小](https://developers.openai.com/api/docs/guides/speech-to-text)、[multipart/verbose 响应契约](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。运行接口可替换，不要求使用 OpenAI 服务。
