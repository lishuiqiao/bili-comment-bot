## 自动化验证范围

- 离线回归覆盖登录续期、消息采集、额度争抢、业务阈值、安全契约、取消、重启、事务与人工恢复。测试禁止真实网络；HTTP 响应与模型答案为合成样例。
- CI 执行 pytest、Ruff、格式、示例配置、离线演示与评测检查，并在仓库外安装 wheel 验证入口与评测数据。
- CI 使用 Docker 实际构建镜像，检查 Compose、非 root、持久卷权限、无凭据启动失败和双命名空间健康；测试容器禁用网络。
- 公开文件检查拒绝私人运行文件、常见密钥标记、个人主机路径及会话链接。它不保证识别所有敏感信息。
- 离线评测只验证明确覆盖的规则与引用；未执行的模型判断标为 not_evaluated。completion 尝试与实际 HTTP 请求分别计数，不以合成答案推断真实模型效果。

CI 的当前结果以仓库 Actions 为准。真实扫码、Cookie 完整续期、平台收发、模型效果与媒体转写质量须在受控账号和供应商上另行验证；自动测试不能替代这些验收。

## 真实验收执行清单

按 [部署手册](deployment.md) 扫码后，在默认模拟模式用两账号核对关注/反向关注、不关注召唤、原楼层、重复事件、频道独立额度及白名单。核对自动续期与失效停止；低/高阈值与 unknown 依赖不得越过。在测试视频和受控用户上启用 live 后核对点赞、鼓励、邀请顺序和数字回执，再测试重启去重。安全拒绝和额度同样适用于违规召唤/私信。

按 [评测手册](evaluation.md) 执行真实模型评测和两位人类评分，实际单/多 P 字幕/音频校对内容；完整口述证据不等于画面理解。社区 API 可能改变，关注方向资料冲突仍须双账号实测。认证或写入结果不确定时停发/人工核实，禁止自动重试 unknown。
