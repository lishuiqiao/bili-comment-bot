# 项目优化方案与验收

本轮检查覆盖配置与控制台、平台认证和采集、数据库事务与发布去重、视频证据、云端/本地推理、调度退出、测试和部署配置。按可复现的问题优先改进，不对缺少测量依据的模块做大规模重写。

| 优先级 | 发现与影响 | 实施方案 | 验收依据 |
|---|---|---|---|
| P1 | 抽帧只接受目标时间之后的帧，单帧/低帧率视频可能全部落空 | 保留目标前的候选帧，在没有后续帧时使用；校验并去重实际时间戳 | 合成单帧视频、原有多帧采样和非法媒体测试 |
| P1 | 本地任务创建时被取消可能丢失子进程句柄；子进程错误缺少可操作分类 | 等待创建收尾后回收进程；使用固定错误码传递上下文超限、解码失败等原因，不传原始异常 | 取消发生在创建期间、超时回收、错误内容脱敏测试 |
| P2 | 过期缓存只失效不清理，长期扫描不同视频会积累无用数据 | 建立 namespace/到期索引，写入时每次最多清理 100 条过期缓存 | 批次上限、命名空间隔离、有效缓存保留及索引查询计划测试 |
| P2 | 页面每三秒重复传输所有设置和 JSON schema | 增加仅含运行状态、健康指示和配置版本的接口，加载/保存时仍取得完整配置 | 鉴权、无设置/密钥/用户内容、响应体大小和版本变化测试 |
| P2 | 零下载预算仍发起网络请求，已知超大内容仍读取响应体 | 请求前拒绝非正预算，可信格式的 Content-Length 超限时提前拒绝，仍保留实际流量上限 | 零请求、未读取响应体、无长度或错误长度时的流式限制测试 |

同时保留本地模型启动失败的具体脱敏提示，避免网页错误地要求本地用户填写 API 密钥。所有修改运行全量测试、格式检查、公开文件隐私检查，再提交到 main。

范围限制：不删除历史消息、发布记录、配额或人工核实记录；不自动开启真实发布。真实 B 站访问和完整模型推理质量不由合成测试替代。本轮不把模型下载或真实性能测量列为已完成事项。

## 实施结果

上述五项均已实现，新增针对性回归。使用默认配置测量相同 JSON 编码方式的接口响应：原完整响应 12,915 字节，状态响应 189 字节，响应体减少约 98.54%（不含 HTTP 头；实际配置会影响数值）。控制台加载和保存仍保留完整数据，状态轮询只携带版本号以检测其他页面的配置修改。

缓存索引随 schema 7 幂等创建；每次写入最多移除本命名空间的 100 条过期项，不执行 VACUUM 或删除持久业务记录。释放的 SQLite 页面可由后续写入复用，不保证数据库文件立即缩小。

本地错误通过固定代码记录，例如 `local_context_budget`、`local_media_invalid`、`local_models_not_prepared`；未知异常统一为 `local_inference_failed`。不会记录模型输入、媒体内容、路径或异常原文。

验收：全量 502 项测试通过（含 18 项新增回归）、Ruff 检查与格式检查通过；独立 wheel 安装后通过配置检查、模拟演练与离线评测。离线评测不调用模型，不代表真实模型质量验收。
